Cada capítulo es un objeto dentro de data/temario.json: tiene un título, la lista de bloques disponibles (para no agobiar con opciones), sus ejemplos y sus tests. Los bloques que se montan solos se definen en js/constructores.js, asociados por el id de cada ejemplo o ejercicio.

Para crear un ejemplo nuevo sin programar: monta los bloques aquí arriba y pulsa este botón para copiar el JSON nativo de Blockly; pégalo como estado del ejemplo o ejercicio en data/temario.json.

Bloques estándar de Blockly + bloques propios del taller: mostrar( ), tipo de ( ), pedir( ), cadenas, listas y funciones. Estructura: Temario → Capítulo → Ejemplos / Ejercicios, con bloques filtrados por capítulo.
